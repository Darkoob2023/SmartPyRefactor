# Python Code Analyzer & Advanced Refactor

A professional tool for **analyzing and optimizing Python code** with a graphical interface.  
Designed for students and developers to **check code quality, get a score, and view optimized code suggestions**.

---

## ⚡ Features

- **AST-based code analysis**  
- **Accurate scoring** based on **Pylint + AST**  
- **Automatic refactoring:**
  - Convert `for + append` loops into **list comprehensions**  
  - Detect and warn about **nested loops**  
  - Detect **long functions** and suggest splitting them  
  - Recommend **using `set()`** for duplicate lists  
- **Before / After code display** with color highlighting  
- **Line-by-line diff** between original and optimized code  
- **Simple and user-friendly GUI** built with **Tkinter**
